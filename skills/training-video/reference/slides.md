# Слайдове — компоненти

1920×1080. Пиши само тялото на слайда (`slides/<id>.html`). Пример за всеки компонент: `${CLAUDE_SKILL_DIR}/deck/catalog/slides/` (k00–k08); каталогът в дадена тема: `node ${CLAUDE_SKILL_DIR}/deck/render.cjs --catalog <тема>`.

## Анимация

- `data-b="N"` — появява се в началото на реплика N на слайда (от 0); `data-d="0.4"` — с толкова секунди по-късно.
- `data-fx`: `up` (по подразбиране), `fade`, `pop` (за акценти), `left`, `right`.
- `data-hl="N" data-hl-end="M"` — осветява елемента между реплики N и M (`.hl-item` го показва с рамка).
- `.kb` около `<img>` — бавно приближаване (фонова снимка); `.bob` — леко поклащане (илюстрация).

## Оформления (`layout` в script.json)

| layout | За какво | Тяло |
|---|---|---|
| `content` | всичко обикновено | компонентите по-долу; заглавието „ЧАСТ n · Заглавие“ се слага само |
| `title` | първи и последен слайд | `.title-wrap` с `.title-logo` (`<img src="{{logo_on_light}}">`), `.t1` (с `<span>` за акцентен ред), `.t2`, `.pill`, `.contacts`; по избор `.bg.kb` с `<img src="{{title_image}}">` + `.shade`, или `.photo-circle` |
| `alert` | едно правило, което не бива да се пропусне | `.alert-wrap` с `.alert-ico`, `.alert-t` (`<u>` за ключовата дума), `.alert-s` |

## Компоненти за `content`

| Клас | Какво |
|---|---|
| `.lead` | въвеждащо изречение под заглавието |
| `.quote` (+ `<span>` в акцент) | ключово послание |
| `.grid-2` / `.grid-3` / `.grid-4` | мрежа от карти |
| `.card` (+ `.pale`, `.filled`, `.outline`, `.wide`) | карта: `h3`, `p`, `ul`; `.num` (01, 02…), `.ico` (икона/символ), `.label` |
| `.chips` | редица от етикети: `<span>` за надпис, `<b>` за всеки етикет |
| `.hl-item` | плочка, която светва с `data-hl` (`<i>` за номер) |
| `.stats` > `.stat` | големи числа: `<b>9+</b><div>години<small>пояснение</small></div>` |
| `.big` | голямо число в акцент (напр. в `.card.wide`) |
| `.card.price` (+ `.rec` за препоръчана) | цена: `.ribbon`, `.pk` (вид), `h3`, `.pv` (сумата), `ul`, `.warn-box` |
| `.card.calc` | сметка: `.calc-t`, `.calc-row` (`<em>+</em>`, `<strong>резултат</strong>`) |
| `.claim` + `table.cmp` + `.verdict` | възражение/твърдение, сравнителна таблица (`td.bad`, `td.win`, `th.win`), извод |
| `.steps` > `.stp` | процес: `.sn` (номер), `h3`, `p` |
| `.rows` > `.card` | изисквания в редове: `.ico` + текст, `.tag` за допълнение |
| `.faq` > `.card.qa` | въпрос (`.q`) и отговор (`.a`) |
| `ol.recap` > `li` > `span` | обобщение с номера |
| `.split` | две колони (текст + снимка) |
| `.shot` | рамка за снимка/скрийншот: `<div class="shot"><img src="img/x.png"></div>` |
| `.code` | код (тъмен блок) |
| `.note`, `.cap` | бележка под линия, надпис под снимка |

## Правила

- Един слайд — една мисъл; до около 40 думи на екрана. Екранът показва ключовите думи и числа, гласът — изреченията.
- Числата на екрана с цифри и единици („4 490 €“, „12 месеца“), както в субтитрите.
- Не повтаряй на екрана цели изречения от гласа.
- Шрифтът не по-малък от 26 px (базовите компоненти го спазват).
- Ред `OVERFLOW` от `stills` — съдържанието излиза от слайда: съкрати или раздели.
- Снимки от материалите — само ако помагат (продукт, екран, схема); не декорация.
