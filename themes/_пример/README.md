# Примерна тема — какви материали трябват

Копирайте тази папка като `themes/<име>/` (например `themes/acme/`), сложете материалите по-долу и попълнете `theme.json`. Скилът сам прави `theme.css` от `theme.json`.

| Какво | Къде | Изискване |
|---|---|---|
| Лого за светъл фон | `logo/on-light.svg` (или `.png`) | SVG за предпочитане; PNG поне 800 px широко, прозрачен фон |
| Лого за тъмен фон | `logo/on-dark.svg` (или `.png`) | Бяло или светло; ако няма, се ползва версията за светъл фон в бяла кутия |
| Цветове | `theme.json` → `colors` | HEX: `dark` (заглавни слайдове, фон), `primary` (основен акцент), `accent` (втори акцент, предупреждения), `background` (фон на слайдовете), `surface` (карти), `ink` (текст), `muted` (бележки) |
| Шрифт за заглавия | `fonts/<файл>.ttf` или `.woff2` | Файлът + лицензът му (OFL, фирмен лиценз). Трябва да има кирилица |
| Шрифт за текст | `fonts/<файл>.ttf` или `.woff2` | Същото; може да е същият файл |
| Фонова снимка за заглавния слайд (по избор) | `images/title.jpg` | 1920×1080 или по-голяма, без текст върху нея |
| Футър (по избор) | `theme.json` → `footer` | Напр. „Ерида · Обучение за екипа“ |
| Надпис за части | `theme.json` → `part_label` | По език: „ЧАСТ“ / „PART“ |
| Тон (по избор) | `theme.json` → `tone` | Едно-две изречения: как говори марката. Гласът остава професионален, корпоративен |

Ако имате брандбук (PDF) — сложете го в папката като `brandbook.pdf`: скилът ще вземе цветовете и правилата от него и ще ви покаже темата за одобрение.

Не слагайте тук материали, които не бива да излизат извън фирмата: темата се разпространява с плъгина до целия екип.
